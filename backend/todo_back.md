## New Features

## Phase 49: Mock Shopping Cart API
- [x] **Mock Shopping Cart API**
  - **Goal:** Mock endpoints for managing a shopping cart.
  - **Details:** Add endpoints to get the cart (`GET /api/cart`), add items to the cart (`POST /api/cart/items`), remove items from the cart (`DELETE /api/cart/items/{item_id}`), and clear the cart (`DELETE /api/cart`).
